**Performance that users can feel.** Investigated frontend bottlenecks with Lighthouse and applied code splitting, lazy image loading, and memoization to improve a production application's performance score **from 62 to 92** while reducing page-load time by **35%**.

**Reliable SaaS experiences.** Developed multi-tenant dashboards and workflows for a platform serving **200+ businesses**, integrating payments, bookings, and analytics alongside **Playwright** end-to-end testing.

**Enterprise AI interfaces.** Built conversational AI experiences, an **MCP-based SharePoint integration** for enterprise document access, and frontend **Content Security Policy (CSP)** protections.

**Across web and mobile.** Shipped responsive web applications and React Native experiences supporting business operations and logistics.
